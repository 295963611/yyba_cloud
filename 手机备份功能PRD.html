在现有「相册/视频/音频」媒体自动同步之外，新增面向手机本地文件系统的浏览与手动备份能力

1. 背景与目标

现状：客户端目前只同步系统媒体库（相册照片、视频、音频），用户手机里的文档、压缩包、安装包、微信/浏览器下载文件、工作目录等无法主动备份；用户也无法按"文件夹"为单位把手机内容原样保存到网盘。

受影响的时刻：用户整理文件、换机前备份、归档票据/合同/资料时，需要在网盘里按手机原本的目录结构找到这些文件。

产品决策：在网盘页提供「手机备份」入口，用户浏览手机本地存储、选择任意文件夹或文件，手动将其按原目录结构备份到网盘专属区域；已通过相册同步备份过的内容自动识别为"已备份"，不重复上传、不重复占空间。

可观察的完成结果：用户在手机上选择一个文件夹并点同步后，网盘 phoneBackup/<设备名>/ 下出现与手机一致的目录结构与文件；本地列表中这些文件状态变为"已备份"；下次进入无需重传。

3. 产品模型

3.1 两条备份线的关系（重要）

系统中并存两类备份，组织方式不同但同属一个网盘文件体系，与群晖（Photos 与 Drive）、飞牛 OS（相册与文件）的做法一致：

维度相册同步（现有）手机备份（本次新增）
内容照片 / 视频 / 音频任意类型文件与整个文件夹
组织逻辑按媒体库分类与时间严格镜像手机源目录结构
触发自动/手动同步本期纯手动
网盘位置photos/、videos/、audio/phoneBackup/<设备名>/
恢复语义回到相册浏览按原目录结构找回
同一份内容不重复存：若手机里的照片已通过相册同步进入云端，在手机备份中再次选到它时，只显示"已备份（相册）"并跳过上传。两条线共享同一套文件指纹去重与回收站体系。

3.2 路径镜像规则

云端目标路径 = phoneBackup / 设备名 / 手机相对路径，其中"手机相对路径"以主存储根为起点逐段镜像，包含中文字符与原文件名：

手机本地路径网盘目标路径
Download/发票/a.pdfphoneBackup/Mi14/Download/发票/a.pdf
DCIM/Camera/IMG_1001.jpgphoneBackup/Mi14/DCIM/Camera/IMG_1001.jpg
Documents/合同/租房.docxphoneBackup/Mi14/Documents/合同/租房.docx

设备名规则

  • 首次进入时默认取手机型号名称（如 Mi14），用户可在备份页顶部编辑，编辑后立即生效，仅影响此后新上传文件的路径。
  • 名称做非法字符清洗（/ \ : * ? " < > | 及首尾空格、点号替换为 _），长度上限 32；为空或清洗后无有效字符时回退为 Android设备。
  • 多台同型号设备的重名由用户通过编辑设备名自行规避 假设。

3.3 与现有能力的衔接

以下能力在产品侧视为既有能力直接复用，不重新设计：分片上传、断点续传、指纹秒传（内容已在云端时不重复占用存储）、前台同步通知、取消机制、云端文件列表/搜索/缩略图/回收站。手机备份产出的文件与普通网盘文件行为一致，但不出现在相册、视频、音频分类视图中。

4. 功能需求

FR-01P0网盘页入口
目的
让用户从网盘上下文进入"把手机内容存入网盘"的流程。
布局
网盘 tab 顶部操作区，「回收站」按钮旁新增「手机备份」按钮（图标 + 文字）。
触发
任意已登录用户点击，进入手机备份页。
结果
打开手机备份页（FR-03）；若尚未获得文件访问权限，先进入授权引导（FR-02）。
FR-02P0文件访问权限引导
目的
浏览完整本地目录树需要"所有文件访问"权限，须向用户说明用途并引导到系统设置开启。
处理规则
  • Android 11 及以上：检查"所有文件访问"授权；未授权时展示授权页（图标、用途说明「用于浏览并备份您选择的手机文件，不会读取未选择的内容」、按钮「去授权」），点击跳转系统"所有文件访问"设置页。
  • Android 10 及以下：使用既有的存储读权限，按系统运行时授权流程处理。
  • 从系统设置返回页面时自动重新检测；授权成功则进入浏览；仍未授权则停留授权页。
禁止操作
未授权时不展示任何文件列表，不进行后台扫描。
异常
部分定制 ROM 无法定位授权设置页时，提示用户手动进入「设置 → 应用 → 本应用 → 权限 → 所有文件访问」。
FR-03P0本地文件浏览
目的
用户按熟悉的手机目录结构找到要备份的内容。
布局
顶部：当前设备名（可编辑）+ 路径面包屑（如 内部存储/Download/发票，点击上级段可跳转）。
快捷入口行：当根目录下存在这些目录时显示快捷入口 —— 相机(DCIM)、下载(Download)、电影(Movies)、图片(Pictures)、文档(Documents)。
列表：文件夹在前、文件在后，各自按名称排序；每行含图标、名称、文件夹项显示"x 项 · 已备份 y 项"，文件项显示大小与备份状态徽标。
处理规则
  • 点击文件夹进入下一级；系统返回键/返回按钮回到上一级；位于根目录时再按返回退出页面。
  • 默认不显示隐藏文件/文件夹（"." 开头）。
  • 0 字节文件正常显示、可选择、可备份。
  • 文件类型图标按 图片/视频/音频/文档/压缩包/安装包/其他 区分；不生成本地缩略图 假设，P0。
状态
列表项状态由 FR-04 给出；进入文件夹后异步计算，先展示内容再逐步回填状态，浏览不被阻塞。
异常
无权读取的目录：该行置灰并标注"无法访问"，不可选择；目录为空时空状态提示"该文件夹为空"；存储未挂载/被拔出时提示并不可操作。
FR-04P0备份状态识别（去重）
目的
让用户在选择前就知道哪些内容已经在网盘里，避免重复备份。
处理规则（按顺序命中即止）
  1. 本机备份记录优先：图片/视频/音频若已被现有相册同步成功上传（本机 sync_records 存在有效记录），直接标记为 已备份·相册，不产生网络请求。
  2. 云端指纹批量校验：未命中本机记录的文件，先在本机计算 SHA-256 指纹，再通过现有 POST /api/files/verify-sync 接口分批校验（每批 50 条，随目录浏览分页懒触发）——请求只带 fileHash（及文件大小），不带云端 relativePath，使同一内容无论位于相册目录还是 phoneBackup 都能命中；命中后按返回记录中的云端路径前缀区分来源：phoneBackup/ 开头标记 已备份·手机备份，其他位置标记 已备份·相册，云端路径可在行详情查看。非媒体文件没有拍摄时间等媒体字段，只能走指纹校验通道。
  3. 未命中：标记 未备份。
  4. 计算中的文件显示 校验中…；指纹计算与批量校验均在后台进行（调度方式对齐现有 SyncVerifyScheduler 的窗口节流/分页模式），不阻塞浏览与页面操作；校验失败不阻断浏览，该项按未备份处理并在发起同步前重试。
接口现状（已核实）：旧的全量 sync-index 拉取客户端已停用，仅保留空实现；当前统一走 verify-sync 的"批量校验 + 懒重建"模式，本功能直接沿用，不重新引入全量索引同步。
文件夹汇总
文件夹行显示 已备份 y / 共 x 项（递归统计）；全部已备份时文件夹整体呈现已备份样式；统计随子项校验完成动态更新。
匹配边界
P0 仅在当前登录用户自己的云端文件范围内匹配，不跨用户、不因他人共享文件而判定已备份。
变更判定
文件大小或指纹与云端记录不一致（文件被修改过）时，视为 未备份，备份按 FR-06 覆盖规则处理。
FR-05P0选择与发起同步
选择规则
  • 长按列表项或点击行首勾选圈进入多选模式；多选模式下点击勾选圈切换选中，点击行其他区域不退出多选。
  • 选中文件夹 = 递归选中其下全部文件（含所有子目录）；底部操作栏显示选中文件数与总大小，并自动扣除已备份项，展示"将上传 n 项 · x.x GB，跳过已备份 m 项"。
  • 支持全选当前目录；已备份项允许勾选但执行时自动跳过。
  • 进入/退出多选模式不丢失已选内容（跨目录选择保留选择集）；退出多选清空选择。
触发条件
"开始备份"按钮在"扣除跳过后实际上传项 ≥ 1"时可用；全部为已备份时按钮置灰，文案"所选内容均已备份"。
发起前
若存在仍处"校验中"的选中文件，先等待其校验完成以确定上传/跳过，再开始。
结果
启动前台同步任务（FR-07），页面进入同步进度态。
FR-06P0同步执行与落盘
执行方式
以前台服务执行，通知栏显示不可消除的进度通知（文件名、总进度）；应用退到后台或熄屏后继续。
处理规则
  • 按 3.2 路径镜像规则逐文件上传，云端自动创建不存在的中间目录。
  • 复用现有分片上传与断点续传；上传时携带文件指纹，服务端确认内容已存在时按秒传完成（跳过实际传输、不重复占空间）。
  • 同设备同路径且指纹不同（本地文件已更新）：覆盖云端旧内容，保持"镜像"语义；历史版本不在本期范围。
  • 已备份项（FR-04 命中）直接计入跳过，不发起上传。
完成后状态变更
文件在网盘中立即可见、可下载、可删除（进入回收站）、图片/视频有缩略图；本地列表状态更新为已备份·手机备份；本机写入备份记录（含 remoteFileId 与指纹），后续进入目录时 FR-04 可直接命中或经 verify-sync 快速校验。
删除语义
本地删除文件不会删除云端副本——手动备份是"快照"，云端内容保留到用户在网盘里主动删除为止。
FR-07P0进度、取消与结果
进行中
页内进度卡片显示：总进度（第 n/共 N 项）、当前文件名、单文件进度百分比、已上传大小；通知栏同步展示。
取消
用户点击"取消同步"：当前文件在当前分片传输完成后中止，未开始的文件不再传输；已上传完成的文件保留在云端并标记为已备份；取消后进入结果页，状态标注"已取消"。
结果页
展示 成功 n 项 / 跳过（已备份）m 项 / 失败 k 项 / 已取消；失败项列出文件名与原因；提供「重试失败项」（k>0 时）与「完成」。
重试
仅对失败项重新执行一轮，其余规则不变。

5. 共享规则（唯一口径）

5.1 备份判定总流程

① 本机记录媒体文件已有相册同步成功记录 → 已备份·相册
② verify-sync 批量指纹校验SHA-256（50 条/批分页）命中本人云端 → 按云端路径前缀标来源
③ 未命中标记未备份，纳入待上传
④ 上传秒传兜底上传时服务端再校验指纹，内容已存在则秒传完成

同一文件在页面上永远只有一个备份状态；任何环节判定为已存在即不再重复传输。

5.2 计数口径

  • 文件夹"共 x 项"= 其下所有层级的文件数（不含文件夹本身，不含隐藏项）。
  • "已备份 y 项"= 状态为 已备份·相册 或 已备份·手机备份 的文件数。
  • 一次同步结果中的"跳过"= 发起前已备份 + 传输中被秒传确认的项之和，结果页可展开区分 假设。

5.3 命名与路径冲突

  • 云端目录不存在时按镜像自动逐级创建；文件名保持与手机一致。
  • 同设备内两个不同本地文件不会映射到同一云端路径；同名冲突只可能来自"文件被修改"，按 FR-06 覆盖处理。
  • 设备名变更不迁移历史文件（旧目录保留），仅影响变更后的路径。

5.4 权限与隐私

  • 仅在用户进入手机备份页并授权后访问文件；只读取用户选中路径及其子内容用于备份，不做后台扫描、不收集文件清单用于其他用途。
  • 所有传输与访问沿用现有登录鉴权，文件归属当前用户空间。

6. 文件备份状态机

状态含义进入条件允许的操作
校验中正在计算指纹/查询云端进入目录后短暂存在可浏览；可勾选（发起前等待校验完成）
未备份本人云端不存在相同内容指纹未命中可勾选、可同步
已备份·相册已由相册同步上传（本机记录或云端命中 photos/videos/audio）规则①②命中可查看云端位置；勾选后同步时跳过
已备份·手机备份已存在于 phoneBackup 目录云端指纹命中同上
备份中正在上传（含排队）同步任务处理到该文件可随整批取消，不可单选
备份失败该文件本轮上传失败网络/服务端/存储异常随「重试失败项」重试
已备份·手机备份 已备份·相册 未备份/校验中 失败

7. 异常与边界

场景产品行为
未授予文件访问权限展示授权引导页，不可浏览；返回应用自动复检（FR-02）
个别目录/文件不可读行置灰标注"无法访问"，不阻塞其他内容；若选中文件夹内含不可读文件，结果中单独提示
同步中网络中断当前文件计为失败，保留断点；其余文件继续尝试；可重试失败项续传
登录态失效中止本轮同步并提示重新登录；已完成文件保留；登录后可重试
云端空间不足当前文件失败并明确提示"云端存储空间不足"，后续文件不再尝试；结果页引导去网盘清理
同步中手机本地文件被删除/移动该文件计失败，原因"源文件已不存在"；不影响其他文件
取消同步完成当前分片后停止，已完成文件保留（FR-07）
应用被杀/重启前台服务通知随之结束；未完成文件状态仍为未备份，重新进入可再次发起；已完成文件因有本机记录而显示已备份
云端同路径文件在网页端被删（进回收站）下次指纹/路径校验发现云端不存在有效文件时，状态回到未备份，重新备份会在同路径生成新文件
大文件/大量文件指纹计算与上传均分片、分块进行；单文件大小上限沿用现有上传能力，不新增限制
应用私有目录/Android/data 等系统屏蔽目录不展示、不承诺可达
重复点击开始备份任务运行中入口与按钮置为"同步进行中"，禁止并发第二轮
