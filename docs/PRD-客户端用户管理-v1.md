---

## 1. 方案

### 启动器 Tab 结构

```
├── 服务配置（已有）
├── 账号注册（已有，保留：首次开户 / 快速注册）
└── 用户管理（新增：列表 + 添加成员 + 启用/禁用）
```

### 与 Web 对齐的能力

| 能力 | Web | 启动器 |
|------|-----|--------|
| 用户列表 | ✅ | P0 |
| 添加成员（MEMBER） | ✅ | P0 |
| 启用/禁用 | ✅ | P0 |
| Android 用户管理 | — | **不做** |

### 分工

- **账号注册**：首个用户自动 ADMIN；适合初始化
- **用户管理 → 添加账号**：走 `createByAdmin`，新建用户固定为成员

---

## 2. 验收标准

- [ ] 用户管理 Tab 展示全部用户（用户名、显示名、角色、状态、创建时间）
- [ ] 可刷新列表
- [ ] 可添加成员账号，创建后立即可 Web/Android 登录
- [ ] 可选中用户启用/禁用，规则与 Web 一致（不能禁用唯一管理员）
- [ ] Android 不增加用户管理入口

---

## 3. 跨端一致性

| 端 | 用户管理 |
|----|----------|
| Web | ✅ 管理员 |
| 启动器 | ✅ 本机管理员工具 |
| Android | ❌ 仅登录使用 |
