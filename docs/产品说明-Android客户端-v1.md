## 1. 产品定位

### 1.1 一句话

> **悠悠爸云盘 Android 版**，是家庭私有云盘的手机伴侣：在家连上云盘服务器，把相册、视频、音频备份到家里，与家人互相分享、随时浏览。

### 1.2 解决什么问题

| 用户痛点 | Android 版如何回应 |
|----------|-------------------|
| 手机照片怕丢 | 一键/后台自动上传到家庭服务器 |
| 家人想互相看照片 | 分享后，对方在「家庭」里直接浏览 |
| 不知道服务器地址 | 局域网自动发现，点选即可连接 |
| 云端有的、手机还没有 | **云端 Tab** 中标记「未下载」，可下载到手机 |
| 出门在外也想看家里文件 | 连上可访问的服务器地址即可（需网络可达） |

### 1.3 不做什么（边界）

- **不做**账号创建与用户管理（在 Web 或启动器完成）
- **不做**服务器存储目录、回收站天数等系统配置
- **不做**公网网盘式「分享链接给陌生人」
- **不替代** Web 端的管理与网盘上传能力

## 2. 目标用户

| 角色 | 典型场景 |
|------|----------|
| 家庭成员 | 备份手机相册，看家人分享的照片/视频 |
| 家长 | 定期点「立即同步」，确保孩子照片进家庭云 |
| 技术较少的用户 | 自动发现服务器，少填 IP |
| 管理员 | 用手机浏览、下载；账号管理仍用 Web/启动器 |

## 3. 信息架构

### 3.1 底部导航（2 个主 Tab）

```
┌─────────────────────────────────────┐
│  首页          │        网盘         │
└─────────────────────────────────────┘
```

| Tab | 作用 |
|-----|------|
| **首页** | 连接状态、未同步统计、四大内容入口、立即同步 |
| **网盘** | 按文件夹浏览云端文件（类似手机文件管理器） |

### 3.2 首页内容入口

| 入口 | 内容 |
|------|------|
| 相册 | 手机照片 + 云端照片 |
| 视频 | 手机视频 + 云端视频 |
| 文档 | 手机/云端/家庭/我分享；支持 PDF、Word、Excel、PPT、TXT |
| 音频 | 手机音频 + 云端音频 |
| 回收站 | 已删除云端文件的恢复与永久清除 |

### 3.3 媒体列表子 Tab（进入相册/视频/音频/文档后）

| 子 Tab | 含义 |
|--------|------|
| **手机** | 仅本机媒体；状态 **未同步 / 已同步**（默认进入） |
| **云端** | 仅云端索引；状态 **未下载 / 已下载** |
| **家庭** | 其他家庭成员分享给自己的内容 |
| **我分享** | 自己已分享给家庭的内容 |

> 文档与相册/视频/音频一致，均为四 Tab；应用内不预览文档，可下载后用系统 App 打开。压缩包等杂项文件本期不提供首页入口。

## 4. 核心功能

### 4.1 连接与登录

| 功能 | 说明 |
|------|------|
| 手动登录 | 填写服务器地址、端口、用户名、密码 |
| 局域网自动发现 | 启动后自动搜索家中云盘（加密地址，约 5 秒），多台时弹窗选择 |
| 记住登录 | 下次启动先连上次服务器，正常时 2 秒内进入 |
| 设置 | 改服务器、开关自动发现、仅 WiFi 同步、后台自动同步、退出登录 |

**用户路径：**

```
打开 App → [自动发现服务器] → 选择/确认地址 → 输入账号密码 → 进入首页
```

### 4.2 备份与同步

| 功能 | 说明 |
|------|------|
| 立即同步 | 首页一键上传：照片、视频、音频 |
| 未同步统计 | 首页显示「未同步照片 X 张 / 视频 X 个」 |
| 单文件同步 | **手机 Tab** 里未同步项可单独上传，带进度 |
| 后台自动同步 | 默认**关闭**；开启后约每 30 分钟检查；可设仅 WiFi |
| 智能去重 | 已上传过的不会重复传 |
| 大文件续传 | 分片上传，中断后可续 |

**同步状态标签（手机 Tab）：**

| 标签 | 含义 |
|------|------|
| 未同步 | 仅在手机，还没上传到云端 |
| 已同步 | 已与云端建立有效关联 |
| 已分享 | 已同步且已分享给家庭（角标，不改变主状态） |

**下载状态标签（云端 Tab）：**

| 标签 | 含义 |
|------|------|
| 未下载 | 云端有，手机尚无可用副本 |
| 已下载 | 手机已有（含本机原本就有的文件） |

> 一键同步**不包含**文档；文档需在文档列表里逐条同步。

### 4.3 云端下载（相册/视频/音频）

| 规则 | 说明 |
|------|------|
| 入口 | **云端 Tab** 中「未下载」项 |
| 下载目标 | 照片/视频写入**系统相册**，并建立 **已同步** 关联 |
| 智能关联 | 若手机已有同图/同视频，自动关联，**不另存副本** |
| 重复下载 | 提示「已在本地」，云端 Tab 显示 **已下载** |
| 双 Tab 联动 | 下载后：云端 Tab → **已下载**；手机 Tab 对应项 → **已同步** |
| 网盘下载 | 保存到手机 **Downloads** 文件夹 |

**用户路径：**

```
相册 → 云端 Tab → 未下载照片 → 预览/长按 → 下载
     → 云端 Tab 变为「已下载」；手机 Tab 出现/更新为「已同步」
```

### 4.4 家庭分享

| 规则 | 说明 |
|------|------|
| 分享对象 | 同一云盘上的家庭账号 |
| 前提 | 须**先同步到云端**才能分享 |
| 操作 | 多选后「分享选中 / 取消分享」；支持一键分享全部 |
| 家庭 Tab | 浏览他人分享，显示分享者名称；可预览、可下载 |
| 我分享 Tab | 管理自己分享出去的内容 |

### 4.5 预览与播放

| 类型 | 能力 |
|------|------|
| 图片 | 左右滑动浏览；云端图可下载 |
| 视频 | 应用内在线播放；不支持格式提示下载 |
| 音频 | 本地走系统播放器；云端应用内播放 |
| 文档等 | 应用内不预览，提示下载后用其他 App 打开 |

### 4.6 批量操作

**进入多选：** 长按任意条目 → 标题显示「已选 N 项」

| 场景 | 可用操作 |
|------|----------|
| 手机 | 删除所选（本地）、上传/同步、分享/取消分享、一键分享全部 |
| 云端 | 下载所选、删除所选（云端回收站） |
| 我分享 | 取消分享、下载所选 |
| 家庭 | 仅预览与单条下载（无批量菜单） |
| 网盘 | 长按：下载、删除 |

**删除说明：** 媒体「删除所选」仅移入**云端回收站**，**不删除手机本地文件**。

### 4.7 回收站

- 查看已删除的云端文件
- 单条**恢复**或**永久删除**
- 提示保留天数（超期自动永久删除，与服务器配置一致）

## 5. 与 Web 端分工

| 能力 | Android | Web |
|------|---------|-----|
| 手机相册自动备份 | ✅ 核心 | ❌ |
| 局域网发现服务器 | ✅ | ❌ |
| 本机同步状态展示 | ✅ | ❌ |
| 下载写入相册并关联云端 | ✅ | ❌（浏览器下载） |
| 家庭内容预览页下载 | ✅ | ❌ |
| 网盘上传文件 | ❌ | ✅ |
| 用户管理（管理员） | ❌ | ✅ |
| 系统设置（存储目录等） | ❌ | ✅ |
| 我的 / 家庭 / 我分享 | ✅ | ✅ |

**推荐使用方式：**

- **启动器**：在家里的电脑上启停服务、首次开户、用户管理

## 6. 典型使用场景

### 场景 A：新手机第一次用

1. 确保手机与家里云盘在同一 WiFi（或可访问服务器）
2. 打开 App，等待自动发现服务器
3. 用家长分配的账号登录
4. 授予相册/音视频权限
5. 点「立即同步」，等待备份完成

### 场景 B：把云端老照片下到手机

1. 首页 → 相册 → **云端** Tab
2. 找到 **未下载** 的照片
3. 点进预览 →「下载到手机」
4. 云端 Tab 变为 **已下载**；手机 Tab 对应项为 **已同步**

### 场景 C：分享宝宝照片给爷爷奶奶

1. 相册 → **手机** Tab → 长按多选已同步照片
2. 菜单选「分享选中」
3. 对方登录后：相册 → 家庭 → 浏览、预览、下载

### 场景 D：定期自动备份

1. 设置 → 开启「自动后台同步」
2. 建议同时开启「仅 WiFi 下同步」
3. 首页可查看未同步数量，必要时手动「立即同步」

## 7. 使用限制与说明

| 项目 | 说明 |
|------|------|
| 网络 | 需能访问家庭云盘服务器（通常同一局域网；远程需自行打通网络） |
| 同步范围 | 一键同步仅含照片、视频、音频 |
| 视频播放 | 部分格式需下载后用其他播放器观看 |
| 文档预览 | 应用内不支持，需下载后打开 |
| 账号 | 账号由管理员在 Web/启动器创建，App 仅登录 |
| 多选 | 长按进入；无 Web 式「全选本页」按钮 |
| 本地文件 | 删除云端文件不会删手机里的原图 |
| 数据安全 | 服务器地址以加密形式保存与传输；登录凭证单独加密保护 |

## 8. 产品原则（设计取向）

1. **一张图一个身份**：云端下载后与本地合并展示，避免「已同步 + 未同步」两条重复。
2. **先同步再分享**：保证家庭看到的是云端权威副本。
3. **删云不删机**：回收站只动云端，尊重用户对手机本地文件的掌控。
4. **手机做备份，Web 做管理**：端侧分工清晰，不把所有能力堆进一个 App。
5. **家庭场景优先**：自动发现、WiFi 同步、分享浏览，降低长辈使用门槛。

## 10. 附录：名词解释

| 名词 | 解释 |
|------|------|
| 手机 Tab | 仅展示本机 MediaStore 媒体；关心是否已备份（未同步/已同步） |
| 云端 Tab | 仅展示当前账号云端索引；关心是否已在手机（未下载/已下载） |
| 已同步 | 手机文件已与云端路径建立有效关联，内容在服务器上可查 |
| 已下载 | 云端文件在手机已有可用副本（含本机原本就有的情况） |
| 已分享 | 已同步且已对家庭成员开放浏览 |
| 家庭 | 其他成员分享给你的内容，只读浏览为主 |
| 我分享 | 你分享给家庭的内容，可自行取消分享 |
| 立即同步 | 扫描手机媒体库并上传尚未备份的照片/视频/音频 |
