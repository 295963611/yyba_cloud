## 1. 核心方案（已定）

### 首次使用 · 引导注册

- 系统**尚无用户**时，访问 Web 任意页面 → 自动跳转 **`/setup` 引导页**
- 引导页分步完成：**① 配置主存储目录 → ② 创建管理员账号**
- **第一个账号自动成为管理员（ADMIN）**，创建成功后自动登录进入云盘

### 日常使用 · 用户管理

- **不提供公开自助注册**；新成员由管理员在 Web「用户管理」中添加
- 管理员可：查看用户列表、添加账号、启用/禁用账号
- 登录页仅保留登录，无注册入口

```mermaid
flowchart TD

    J -->|是| K[/users 用户管理]
    K --> L[添加家庭成员账号]
```

## 3. 功能清单

### P0（本期）

| 功能 | 验收标准 |
|------|----------|
| 引导页 `/setup` | 无用户时任意访问跳转引导页；有用户时访问 `/setup` 跳转登录 |
| 首次注册 | 创建成功 → 角色 ADMIN → 自动登录 |
| 用户管理 `/users` | 仅 ADMIN 可见；列表展示用户名、显示名、角色、状态、创建时间 |
| 添加账号 | 管理员弹窗创建 MEMBER 账号；新账号可立即登录 |
| 禁用/启用 | 禁用后无法登录；不能禁用自己；不能禁用唯一管理员 |

### P1（后续）

- 编辑显示名称
- 管理员重置密码 / 成员自助改密
